## Pro concepts

- **Local diagram:** stored in the current browser. It can be edited without an account but is not available to Pro integrations.
- **Cloud diagram:** stored in the workspace selected when it is created or uploaded. Cloud diagrams enable Pro sharing, versions, team collaboration, and MCP.
- **Personal workspace:** the private workspace associated with a Solo account.
- **Team workspace:** a shared container with Admin and Member roles. It enables team permissions and live collaboration.
- **Public link:** an unauthenticated, view-only URL for one cloud diagram.
- **API key:** a user-owned secret that authenticates MCP and the read-only schema API.

Core modeling behavior is documented in [Create a database diagram](/create-diagram), [Customize the editor](/customizing-editor), and [Keyboard shortcuts](/shortcuts).

<Callout title="Cloud features need a saved diagram" type="info">
  Pro sharing, version history, collaboration, and MCP work from the cloud copy. AI can also operate on an open local diagram for an eligible signed-in account; its schema is still sent to the AI service as context.
</Callout>
