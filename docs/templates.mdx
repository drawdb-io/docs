## Create a custom template

1. Build or open the diagram you want to reuse.
2. Choose `File → Save as template`.
3. Give the template a useful name and description.

The template will appear when you create a new diagram and on the Templates page.

## Use and manage templates

- Select a template in the New Diagram dialog to create a separate diagram from it.
- Open the Templates page to browse built-in and custom templates.
- Fork a template to begin editing a copy.
- Delete custom templates you no longer need.

<Callout title="Stored in this browser">
  In the open-source editor, custom templates are IndexedDB records stored on the current browser. They are not account-synced or cloud-backed.
</Callout>
