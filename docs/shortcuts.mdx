---
title: Keyboard shortcuts
description: A complete reference for drawDB keyboard shortcuts and mouse controls for saving, importing, editing, canvas navigation, zoom, and view settings.
---

Use Ctrl on Windows and Linux or Command on macOS wherever the table shows `Ctrl/Cmd`.

## Files and editing

| Shortcut | Action |
| --- | --- |
| Ctrl/Cmd + S | Save diagram |
| Ctrl/Cmd + Shift + S | Save diagram as |
| Ctrl/Cmd + O | Open a diagram |
| Ctrl/Cmd + I | Open the import dialog for JSON, DDB, DBML, or SQL input |
| Ctrl/Cmd + C | Copy the selected element |
| Ctrl/Cmd + V | Paste |
| Ctrl/Cmd + X | Cut the selected element |
| Ctrl/Cmd + D | Duplicate the selected element |
| Delete/Backspace | Delete the selected element |
| Ctrl/Cmd + E | Edit the selected element |
| Ctrl/Cmd + Z | Undo |
| Ctrl/Cmd + Y | Redo |

## Canvas and view

| Shortcut | Action |
| --- | --- |
| Enter/Return | Reset the canvas view |
| Ctrl/Cmd + Alt + W | Fit the diagram to the window |
| Ctrl/Cmd + Up or Ctrl/Cmd + wheel up | Zoom in |
| Ctrl/Cmd + Down or Ctrl/Cmd + wheel down | Zoom out |
| Right-button drag or middle-button drag | Pan the canvas |
| Wheel | Scroll vertically |
| Shift + wheel | Scroll horizontally |
| Ctrl/Cmd + Shift + G | Show or hide the grid |
| Ctrl/Cmd + Shift + F | Show or hide field details |
| Ctrl/Cmd + Shift + M | Toggle strict mode |
| Alt + E | Open or close the DBML editor |
| Ctrl/Cmd + Alt + C | Copy the diagram as an image |
| Ctrl/Cmd + H | Open the documentation |

To pan, hold the right or middle mouse button while dragging on the canvas, then release it to stop. A right-click without dragging does not toggle a pan mode.

<Callout title="Browser-reserved shortcuts">
  The browser or operating system may intercept some key combinations. Enter/Return resets the drawDB view; Ctrl/Cmd + R remains the browser refresh shortcut.
</Callout>
